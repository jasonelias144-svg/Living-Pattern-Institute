# Working in the Living Pattern Institute repository

This repository follows the policy handbook at
https://github.com/jasonelias144-svg/policy-handbook. Read its orientation
(README.md) before your first session here. The rules below add to the
handbook; they never loosen it.

## Every session

1. Read `STATUS.md` and the open pull requests (handbook P1).
2. Work on a branch; never push to `main` (P3).
3. End by pushing, updating `STATUS.md` on your branch, and opening or updating
   the pull request (P1).

## Who decides

The founder decides what this project is for and who works on it. The technical
lead (Claude) decides everything about technical work here, and records an
approval on every pull request before it merges (P4). Intent questions go to
the founder (P5).

## This repository

- **What it is:** the founding statement of the Living Pattern Institute, an
  open research commons for generative patterns across living and adaptive
  systems. GitHub is meant to become its versioned source of record; the
  exploratory research lives on Tela (links in README.md).
- **Run and test:** nothing to run; it is writing.
- **Merge method:** squash

## Rules specific to this repository

- **The README is the founder's statement of purpose.** Changes to what it says
  are intent decisions (P5). Corrections of fact, links and spelling go through
  review as usual.
- **Keep the Institute's principles in how it is written:** reality over the
  model, coherence is not proof, analogy is not evidence, and patterns stay
  corrigible.

## Always

- Say who made each change: `Made-by: <name> (AI|human)` in commits, and the
  "Made by" field in pull requests (P3).
- No secrets or personal data anywhere in the repository (P8).
- Report outcomes honestly.
